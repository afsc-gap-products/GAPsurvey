# Calculate oxygen saturation (ml/l)

Calculate oxygen saturation as a function of temperature and salinity
based on oxygen solubility from Garcia and Gordon (1992).

## Usage

``` r
oxygen_saturation(temperature, salinity)
```

## Arguments

- temperature:

  Temperature (degrees Celsius).

- salinity:

  Salinity (PSU, PSS-78).

## References

Garcia, H.E., Gordon, L.I., 1992. Oxygen solubility in seawater: Better
fitting equations. Limnol. Oceanogr. 37, 1307–1312.
https://doi.org/10.4319/lo.1992.37.6.1307
