# Package index

## Marport and Globe Converters

- [`convert_log_gps()`](https://afsc-gap-products.github.io/GAPsurvey/reference/convert_log_gps.md)
  : Recover position data from Globe .log file
- [`convert_bvdr_marp()`](https://afsc-gap-products.github.io/GAPsurvey/reference/convert_bvdr_marp.md)
  : Convert .bvdr files to .marp files

## CTD Converters & Tools

- [`convert_ted_btd()`](https://afsc-gap-products.github.io/GAPsurvey/reference/convert_ted_btd.md)
  : BVDR Conversion to Create BTD data
- [`convert_ctd_btd()`](https://afsc-gap-products.github.io/GAPsurvey/reference/convert_ctd_btd.md)
  : Convert CTD data from .hex to BTD and BTH
- [`convert_nmea_btd()`](https://afsc-gap-products.github.io/GAPsurvey/reference/convert_nmea_btd.md)
  : Extract depth and temperature from NMEA strings
- [`convert_tzdb_gps()`](https://afsc-gap-products.github.io/GAPsurvey/reference/convert_tzdb_gps.md)
  : Read data from a TimeZero database and convert to a .gps file

## Resources
