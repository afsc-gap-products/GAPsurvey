# PolySpecies Data Set

polynumbers

## Usage

``` r
data(PolySpecies)
```

## Format

A data frame with 172 rows and 4 variables:

- `SPECIES_CODE`:

  integer Species code

- `POLY_SPECIES_CODE`:

  integer Poly species code

- `SPECIES_NAME`:

  character Species scientific latin name

- `COMMON_NAME`:

  character Species common names
